OpenCV 실시간 웹캠 보기

동영상 파일 대신 카메라 인덱스를 VideoCapture에 전달하면 실시간 프레임을 받을 수 있습니다. 

cap = cv2.VideoCapture(0)
while cap.isOpened():
    ok, frame = cap.read()
    if not ok: break
    cv2.imshow("camera", frame)
    if cv2.waitKey(1) & 0xFF == ord("q"): break
cap.release()
cv2.destroyAllWindows()

학습 정리

예제를 실행할 때는 입력 데이터의 경로와 shape, 반환값 성공 여부를 먼저 확인하고, 처리 결과를 단계별로 화면에 표시하면 오류 원인을 빠르게 찾을 수 있습니다.

원문 목차를 바탕으로 학습용으로 재서술한 자료입니다.
