HSV 특정영역 마스킹

HSV 색공간은 색상 범위를 분리하기 쉬워 특정 색 영역 추적에 자주 사용합니다.

hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, lower, upper)
result = cv2.bitwise_and(frame, frame, mask=mask)

학습 정리

예제를 실행할 때는 입력 데이터의 경로와 shape, 반환값 성공 여부를 먼저 확인하고, 처리 결과를 단계별로 화면에 표시하면 오류 원인을 빠르게 찾을 수 있습니다.

원문 목차를 바탕으로 학습용으로 재서술한 자료입니다.
