프로젝트 2 - 실시간 웹캠 필터앱

색상 추적, 얼굴 검출, 모션 감지 기능을 하나의 실시간 웹캠 앱으로 통합합니다.

학습 포인트

이 장에서는 앞선 내용을 연결해 전체 OpenCV 처리 흐름을 이해하고 직접 실행 가능한 실습 구조로 정리합니다.

통합 프로젝트
웹캠 입력 → HSV 색상 추적 → 얼굴 검출/모자이크 → 모션 감지 → 화면 출력의 순서로 기능을 모듈화해 결합합니다.
원문 목차를 바탕으로 학습용으로 재서술한 자료입니다.
