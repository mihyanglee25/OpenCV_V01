SECTION 06-02

실시간 필터 적용

매 프레임에 grayscale, blur, edge 등의 변환을 적용하고 지연 시간을 작게 유지하면 실시간 필터를 구현할 수 있습니다. 

gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(frame, (9,9), 0)
edge = cv2.Canny(gray, 80, 160)

학습 정리

예제를 실행할 때는 입력 데이터의 경로와 shape, 반환값 성공 여부를 먼저 확인하고, 처리 결과를 단계별로 화면에 표시하면 오류 원인을 빠르게 찾을 수 있습니다.

원문 목차를 바탕으로 학습용으로 재서술한 자료입니다.
