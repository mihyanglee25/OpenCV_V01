OpenCV 설치 이전

Windows 환경에서 Python, C++ 빌드 도구, CMake를 준비하고 GPU 가속이 필요한 경우 CUDA/cuDNN 호환성을 함께 점검합니다.

권장 점검 순서

  1. Python과 pip가 PATH에서 정상 인식되는지 확인합니다.
  2. CPU 방식은 opencv-python 패키지로 빠르게 시작할 수 있습니다.
  3. CUDA 빌드는 Visual Studio, CUDA, cuDNN, CMake, OpenCV 소스 버전 호환성을 먼저 확인합니다.
python --version
pip --version
