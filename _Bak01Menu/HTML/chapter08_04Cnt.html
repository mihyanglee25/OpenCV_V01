중심좌표 추적

bounding box 또는 moments를 이용해 객체의 중심 좌표를 계산하고 프레임 간 이동을 시각화할 수 있습니다. 

M = cv2.moments(c)
if M["m00"] != 0:
    cx = int(M["m10"] / M["m00"])
    cy = int(M["m01"] / M["m00"])

학습 정리

예제를 실행할 때는 입력 데이터의 경로와 shape, 반환값 성공 여부를 먼저 확인하고, 처리 결과를 단계별로 화면에 표시하면 오류 원인을 빠르게 찾을 수 있습니다.

원문 목차를 바탕으로 학습용으로 재서술한 자료입니다.
