SECTION 05-01

동영상 안전하게 로드

파일 존재 여부와 VideoCapture의 opened 상태를 확인하면 경로 오류나 코덱 문제를 빠르게 구분할 수 있습니다. 

cap = cv2.VideoCapture(path)
if not cap.isOpened():
    raise RuntimeError("동영상을 열 수 없습니다")

학습 정리

예제를 실행할 때는 입력 데이터의 경로와 shape, 반환값 성공 여부를 먼저 확인하고, 처리 결과를 단계별로 화면에 표시하면 오류 원인을 빠르게 찾을 수 있습니다.

원문 목차를 바탕으로 학습용으로 재서술한 자료입니다.
